Concepts table

Repository: The project folder plus its full save history
Working tree: The files you can see and edit right now
Staging area: Your “to-save” pile where you pick which changes go into the next save
Commit: A save point with a short note about what changed
Branch: A separate copy of the work so you can try things without touching the main version
Merge: Joining a finished branch back into the main version
Remote: The online copy of the project such as on GitHub
Push: Sending your saves up to the online copy
Pull: Bringing the latest saves down from the online copy
Clone: Making a full copy of an online project onto your computer
